# PRODUCT.md — orcflood.com

**Product.** Orc Flood: Tower Defense — a premium (free + one non-consumable
unlock, no ads/analytics/accounts, fully offline) pixel tower defense for
iOS + Android. The mechanism that defines it: the horde is not waves, it is
one continuous simulated tide — up to 160,000 orcs per campaign, every one
simulated and counted. Player places up to 28 guns and aims every barrel.

**This site.** Marketing + compliance home at orcflood.com (GitHub Pages,
canonical host `www.orcflood.com`). Surfaces: landing (Persuade), one
comparison/FAQ page `/vs/sir-we-have-an-orc-problem/` (Read → Persuade,
SEO target: "Sir We Have an Orc Problem mobile/iOS/android"), privacy.html
and support.html (Read; their URLs are referenced by live store listings —
paths must never change).

**Audience.** PC tower-defense players looking for the same fantasy on a
phone; searchers asking if the (unaffiliated) Steam game has a mobile port.

**Action.** Install from the App Store / Google Play. Until listings are
live, badges read "coming soon" (swap to official store badges at launch).

**Hard constraints.**
- Truthful stats only, all from the game data: 160,000 orcs final campaign,
  110,000+ alive in the hero screenshot, 7 towers, 4 abilities,
  152 upgrade-tree nodes, 12 campaigns, 3 currencies (scrap/banners/skulls).
- The original game ("Sir, We Have an Orc Problem", Mumpitz Games, Steam)
  is referenced nominatively only: never "official", never "the mobile
  version of", always with a not-affiliated disclosure on the /vs page.
  Its name never appears in our domain or store metadata.
- No third-party requests (no webfont CDNs, no analytics) — GDPR-clean,
  self-hosted assets only.
